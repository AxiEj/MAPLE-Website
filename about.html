About MAPLE

Learn about MAPLE and its machine-learning-potential-native computational chemistry workflows.

Overview

MAPLE is a computational chemistry toolkit for geometry optimization, transition-state search, reaction-path analysis, molecular dynamics, and related workflows driven by machine learning potentials. See the current overview for supported capabilities and the software license terms before use.

Features

  • Geometry optimization and transition-state search
  • Reaction-path, frequency, scan, and molecular-dynamics workflows
  • Multiple machine learning potential backends
  • Task documentation, examples, and model guidance
